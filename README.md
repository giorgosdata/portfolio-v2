# George Oikonomou — Portfolio (v2)

Playful redesign of my personal portfolio. Mobile apps, web apps, and websites I've shipped.

**Live:** https://giorgosdata.github.io/portfolio-v2/  *(once deployed)*

## Tech
- Vanilla HTML / CSS / JS
- [Three.js](https://threejs.org/) — 3D background scene
- [GSAP](https://gsap.com/) + ScrollTrigger — animations
- [Formspree](https://formspree.io/) — contact form
- Font Awesome 6 — icons
- Google Fonts: DynaPuff, Geist, Roboto Mono

## Run locally
Just open `index.html` in a browser — no build step.
